# Leave Application Form

## 📌 Project Overview

The **Leave Application Form** is a web-based application developed using **ASP.NET Web Forms and C#**. The project provides a simple interface for employees to submit their leave details through an online form.

The application is designed as part of a practical project to demonstrate concepts such as **ASP.NET Web Forms, C#, cookies, form handling, and page navigation**.

## 🚀 Features

* Employee leave application form
* Employee name and leave details
* Leave reason submission
* User-friendly form interface
* Cookie-based data handling
* ASP.NET Web Forms implementation
* C# backend functionality
* Simple and easy-to-use design

## 🛠️ Technologies Used

* **C#**
* **ASP.NET Web Forms**
* **.NET**
* **HTML**
* **CSS**
* **Visual Studio**

## 📝 Working of the Application

1. The user opens the Leave Application page.
2. The user enters the required employee and leave details.
3. The application processes the submitted information using C#.
4. Cookie-based information can be retrieved when required.
5. The leave application is processed through the ASP.NET Web Forms page.
